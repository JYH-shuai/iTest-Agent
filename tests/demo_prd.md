# iTest-Agent 演示系统 PRD

## 用户账户模块

### 2.1 用户注册
#### 2.1.1 正常注册
- 打开注册页面 http://127.0.0.1:8090
- 输入手机号 13800138000，密码 Test@1234，昵称 测试用户
- 点击注册按钮，验证提示"注册成功"

#### 2.1.2 密码过短注册
- 打开注册页面 http://127.0.0.1:8090
- 输入手机号 13800138001，密码 Test1（5 位），昵称 测试用户2
- 点击注册按钮，验证提示"密码长度需为 6-20 位"

#### 2.1.3 手机号已注册
- 打开注册页面 http://127.0.0.1:8090
- 输入已注册手机号 13800138000，密码 Test@1234，昵称 重复用户
- 点击注册按钮，验证提示"该手机号已注册"

### 2.2 用户登录
#### 2.2.1 正确账号登录
- 打开登录页面 http://127.0.0.1:8090
- 输入手机号 13800138000，密码 Test@1234
- 点击登录按钮，验证显示"登录成功"

#### 2.2.2 错误密码登录
- 打开登录页面 http://127.0.0.1:8090
- 输入手机号 13800138000，密码 Wrong@9999
- 点击登录按钮，验证显示"手机号或密码错误"
